What each result meansUse this before downloading or calculating state vectors.⌄
Raw detector overlay

Retained, unsmoothed particle coordinates over the camera video. This is the primary tracking validity check.

Smoothed overlay

A post-processed visualization. It can reduce jitter but cannot prove the detector followed the correct particle.

3-D trajectories CSV

Frame/time, raw and smoothed positions, camera coordinates, confidence, z disagreement, and diagnostic columns.

Trajectory projections

A compact plot of the reconstructed motion. Useful for patterns and outliers, but not sufficient for frame-level validation.

Motion/state CSVs

Derived velocity, acceleration, orientation, or angular motion. These depend on confirmed FPS, calibration, and source choice.

Run manifest

Records source, settings, calibration, commands, creation time, and code revision so the output can be reproduced.
